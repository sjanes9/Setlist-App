    How to Use This App

    The two modes

    Edit is where you build songs. Performance is the big-text, auto-scrolling view you use on stage. Switch with the buttons at the top.

    Building a song

    Fill in the title, tempo and time signature, then type or paste lyrics. Use the section buttons (Intro, Verse, Chorus…) to drop in headers — tick “with bars” first to also set how many measures each section runs. The Scroll Mode field picks how auto-scroll is paced, and saves with the song.

    Bar-timed scrolling (the good part)

    When sections have bar counts like {c: Verse 1}{bars:16}, the app knows exactly when each section plays and keeps it under the reading line at the right moment. The song’s duration is then calculated from the bars and tempo — no guessing. Sections without bar counts fall back to even pacing, so you can add them gradually.

    Measure breaks

    Use Add Measures Break to hold the scroll for a set number of bars — handy for intros, solos and turnarounds.

    Set lists

    In the Edit view, create a set list, add songs, and drag rows (or use the ▲/▼ buttons) to reorder. Order saves to your device instantly. Open a set list from the Open dropdown to perform it — use Prev / Next or the Set List button to move between songs. Open a single song instead and the set-list controls stay out of the way.

    Performance controls

    Press Play to start scrolling. The ⏲ metronome clicks at the song’s tempo. The 🎤 count-in listens for four drumstick clicks to auto-start. Tap ☰ Quick Actions for tempo, font size and width. Tap Settings on the dock to expand more controls.

    Importing a Songsterr tab

    In the menu, Import Tab PDF reads a Songsterr tab and builds the song — title, artist, tempo, sections, bar counts and lyrics. Works on tabs that have section labels (Intro/Verse/Chorus).

    Cloud library & backups

    Your library lives on this device. The cloud only changes when you press Upload to Cloud, which asks for a passcode so a stray tap can’t overwrite the band’s copy. Reload from Cloud pulls the shared copy down. Both save a local .json backup file first, so an accidental overwrite is always recoverable. Nothing syncs automatically.

    Tip: keep the occasional backup file somewhere safe. It’s your ultimate safety net.
